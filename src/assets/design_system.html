Tipografia Inter.

Uma família só, do 100 ao 900, com tracking negativo agressivo nos displays (herança ADR) e Geist Mono para metadados.

Primária --font-sans
Aa

Inter

Variável, eixo wght 100–900. Títulos, corpo, UI e números (tabular-nums).

300400500600700800850/900
Fallback stack
Aa

Pilha de fallback

"Inter", "Inter Fallback", Arial, "Helvetica Neue", sans-serif

"Inter Fallback" = Arial com size-adjust (next/font no site ADR) para evitar layout shift.

Monoespaçada --font-mono
{a}

Geist Mono

Labels de seção, tokens, metadados e numeração "01 / 08" (padrão Gemini). Fallback: ui-monospace, Menlo.

Estratégia de carregamento

Produção: auto-hospedada (woff2 variável, subsets por unicode-range). Protótipos: Google Fonts CSS2.

Local

1 woff2 variável por subset (latin, latin‑ext, cyrillic, greek, vietnamese) via @font-face.

CDN

preconnect + wght@100..900 + display=swap.

Performance

Pré-carregar só o latin; fallback com métricas ajustadas para CLS ≈ 0.

Scroll expand

  • clip-path: inset() abre de 40–46% até 100%; raio 32→0px.
  • Mídia desfaz o zoom 1.35→1; título sai (0.40–0.88), overlay entra (0.68–1).
  • Stage sticky · trilho = altura × (1 + 1.2 + 0.35) · smoothing exponencial 0.1s.
  • Dois modos: página (data-se-window, logo após a hero) ou scroller próprio (este card).

Props via data-se-*: start-width, start-height, start-radius, end-radius, zoom, distance, hold, smoothing, scrim, window, enabled.
